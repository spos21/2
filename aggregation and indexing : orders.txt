Problem statement: Create a collection named "ORDERS" that contain 
documents of the following prototype and solve the following queries: 
{ cust_id: "abc123", 
ord_date: new Date("Oct 04, 2012"), 
status: 'A', 
price: 50, 
items: [ { sku: "xxx", qty: 25, price: 1 }, 
{ sku "yyy", qty: 25, price: 1}]} 
 
 
a) Find total order value per customer 
b) Find total quantity of each item ordered 
c) Get total sales for orders with status=”A” 
d) Count all records from orders 
e) Sum the price field from orders 
f) For each unique_id,sum the price field 
g) For each unique cust_id,sum the price field ,results sorted by sum 
h) For each unique cust_id,ord_date grouping ,sum the price field 
i) For cust_id with multiple records , returns the cust_id & the 
corresponding recordcount 
j) For each unique cust_id,ord_date grouping , sum the price field & return 
only where the sum is greater than 55 
k) For each unique cust_id with status A ,sum the price field

  {
    $group: {
      _id: {
        cust_id: "$cust_id",
        ord_date: "$ord_date"
